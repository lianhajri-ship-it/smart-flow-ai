# Smart Flow AI

أتمتة الفواتير بالذكاء الاصطناعي للمنشآت الصغيرة والمتوسطة في السعودية.

## التشغيل

```powershell
py -3.13 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
copy .env.example .env

python -m smart_flow   # تشغيل البرنامج
pytest                 # تشغيل الاختبارات
```
