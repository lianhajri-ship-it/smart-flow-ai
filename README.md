# Smart Flow AI

أتمتة الفواتير بالذكاء الاصطناعي للمنشآت الصغيرة والمتوسطة في السعودية.

## التشغيل

```powershell
py -3.13 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
copy .env.example .env

python -m smart_flow       # معالجة الفواتير في مجلد data/inbox
python -m smart_flow.web   # تشغيل الموقع على http://localhost:8000
pytest                     # تشغيل الاختبارات
```

لفتح الموقع من الجوال: ضعي `HOST=0.0.0.0` في ملف `.env`، ثم افتحي `http://<IP اللابتوب>:8000` من جوال متصل بنفس شبكة الواي فاي.
